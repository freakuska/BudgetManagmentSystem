# Budget Management System

Мобильное приложение для учета личных финансов. Проект сделан как учебная работа: пользователь может войти в систему, добавлять доходы и расходы, распределять операции по тегам и смотреть простую статистику.

Приложение работает с REST API, а часть данных хранит локально через Room, чтобы основные экраны не зависели полностью от сети.

## Что есть в приложении

- регистрация и вход пользователя;
- хранение access- и refresh-токенов;
- список финансовых операций;
- добавление доходов и расходов;
- теги и категории операций;
- экран статистики;
- локальная база данных Room;
- интерфейс на Jetpack Compose.

## Диаграммы

Диаграммы проекта лежат в папке [`docs/diagrams`](docs/diagrams). В репозитории оставлены только схемы, которые относятся к мобильному приложению:

- функциональная структура приложения;
- взаимодействие пользовательских действий с модулями системы.

## Технологии

Kotlin, Android SDK 34, Jetpack Compose, Retrofit, OkHttp, Room, DataStore, Coroutines.

## Настройка API

Адрес API не хранится в исходном коде. По умолчанию debug-сборка обращается к локальному компьютеру из Android Emulator:

```text
http://10.0.2.2:7000/
```

Другой адрес можно передать через Gradle:

```bash
./gradlew assembleDebug -PAPI_BASE_URL=https://api.example.com/
```

В release-сборке незашифрованный HTTP запрещен. Реальные внутренние IP-адреса не нужно добавлять в репозиторий.

## Запуск

1. Установить Android Studio и JDK 17.
2. Открыть корень проекта.
3. Дождаться синхронизации Gradle.
4. Запустить приложение на эмуляторе с Android 7.0 или новее.

## Проверка

```bash
./gradlew test
./gradlew assembleDebug
```
